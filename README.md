# 手稿显影

用手机拍一页本子，自动把纸面拉正、提取笔迹，再换一种光线重新"显影"。整个工具就是一个网页，不需要安装任何应用。

**在线使用：** https://yx0716.github.io/ink-darkroom/

## 怎么用

1. 在 iPhone 上用 Safari 打开上面的网址
2. 点底部的「分享」按钮 → 选「添加到主屏幕」，以后就像 App 一样从桌面打开
3. 点「拍一页」或「从相册选」，拖动四个圆点对准纸张四角，点「显影」
4. 选光线和墨色，然后「分享 / 存储」或「拷贝图片」

## 隐私

所有处理都在手机本地完成，照片不会上传到任何服务器。页面不依赖任何后端或外部资源。
